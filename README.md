US Accidents — Exploratory Data Analysis
Exploratory Data Analysis of the US Accidents dataset consisting of 4.2 million data using Python, Pandas, NumPy, Matplotlib and Seaborn 
 This project performs Exploratory Data Analysis (EDA) on the US Accidents dataset to identify patterns and factors associated with road accidents
 Objectives
Analyze accident frequency across different states
Study accidents by time and day
Identify accident hotspot climate
Study the relationship between temperature and accidents
Visualize accident patterns using graphs and heatmaps

 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

 Dataset

US Accidents dataset containing millions of accident records across the United States.
The dataset is not included in this repository because of its large size.
